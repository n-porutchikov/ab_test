# A/B-тест новой формы оплаты ЖКХ

Краткий анализ результатов A/B-теста, проведённого в апреле 2024 года.

## Описание
Проект содержит анализ A/B-теста новой формы оплаты ЖКХ с упрощённым заполнением реквизитов.  
Цель — оценить влияние новой формы на конверсию из шага 1 (открытие формы) в шаг 4 (успешная оплата).

## Данные
- **Пользователи** (1504 записи): группа (A/B), возраст, город, тип устройства.
- **Платежи** (2661 запись): шаги воронки (открыл → ввёл реквизиты → подтвердил → оплатил).
